# Чеклист «перед релизом» для соло-билдера с AI-агентами (15 минут)

> Короткая версия [`CHECKLIST.md`](CHECKLIST.md) с акцентом на крипто-боты и Hetzner. Приоритеты по этапам — [`ROLLOUT-priorities.md`](ROLLOUT-priorities.md); правила для агента — [`AGENTS-rules.md`](AGENTS-rules.md).

## Безопасность и секреты
- [ ] Авторизация в каждом обработчике / server action; тест «чужой ID → 404».
- [ ] Все входы и env — zod `.strict()`.
- [ ] argon2id/bcrypt; 2FA для админов и вывода; сессии в httpOnly cookie.
- [ ] Next.js и зависимости обновлены; lockfile; `ignore-scripts=true`; Socket/`npm audit` в CI.
- [ ] Вебхуки с проверкой подписи (HMAC по сырому телу, `timingSafeEqual`) и идемпотентностью по event id.
- [ ] Postgres/Redis/Docker не торчат наружу (`ss -tlnp` на сервере, `nmap` снаружи); SSH по ключу; контейнеры не от root.
- [ ] Ноль секретов в git (`gitleaks`) и в `NEXT_PUBLIC_*`; ключи кошельков в signer/KMS; runbook ротации.

## Данные и откат
- [ ] Бэкапы pgBackRest/WAL-G + PITR в другой регион/провайдер; **еженедельное автоматическое тестовое восстановление** + алерт на отсутствие бэкапа.
- [ ] Миграции в CI, expand/contract, `lock_timeout`.
- [ ] Деньги — `numeric`/`bigint`; время — `timestamptz` UTC.
- [ ] Откат одной командой проверен; таймауты/backoff на внешних вызовах; долгие задачи в BullMQ.
- [ ] Идемпотентность выводов и транзакций (Idempotency-Key / подпись / nonce в БД); kill switch для рискованных фич.

## Боты и мониторинг
- [ ] Cloudflare перед сервером, origin закрыт; лимиты по IP / аккаунту / устройству / **кластеру**; Turnstile + email + блок одноразовых доменов; риск-скор и тихие санкции.
- [ ] Sentry, внешний uptime-чек, RED-метрики на эндпоинт, логи с `requestId` без PII.
- [ ] Алерты в Telegram: 5xx, p99, диск, очередь, неудачный бэкап, баланс горячего кошелька, крупный вывод, тишина бота.
- [ ] Runbook-и: откат, восстановление БД, ротация ключей, «нас атакуют боты».

## Крипто-боты
- [ ] Горячий кошелёк — минимальный баланс; whitelist адресов; лимит на транзакцию и на час.
- [ ] 2–3 RPC с фолбэком и таймаутами; один воркер на кошелёк для nonce.
- [ ] `finalized` / N подтверждений для всего необратимого; обработка reorgs идемпотентна по `(tx_hash, log_index)`.
- [ ] Slippage + deadline; приватный mempool / Jito для MEV-чувствительных сделок.

## Процесс с AI
- [ ] `CLAUDE.md` с запретами и командами проверки.
- [ ] План → утверждение → тест → код → ревью диффа вторым агентом → ваш взгляд на `auth/`, `migrations/`, `contracts/`, CI.
- [ ] PR < ~300 строк; агент без доступа к проду, ключам и деплою.

## Что делать / чего не делать
- **Делать:** проходить список перед каждым релизом; не отмечать пункт, пока не проверен руками (особенно восстановление из бэкапа).
- **Не делать:** деплоить в пятницу вечером без отката и присутствия; считать «агент сказал, что протестировал» проверкой.
