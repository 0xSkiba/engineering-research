# Каталог ошибок: что делать не надо

**[Рекомендации/синтез]**. Это не статистический топ; основания раскрыты в тематических главах.

| Ошибка | Последствие | Что делать | Как проверить |
|---|---|---|---|
| Сразу строить десятки микросервисов | Сложность эксплуатации до появления нагрузки | Начать с ясных модулей | Модуль можно менять без обхода всего проекта |
| Делить БД по числу строк | Не устраняется настоящий bottleneck | Профилировать запросы и ресурсы | Замеры до/после |
| Разносить связанные сущности случайно | Межсерверные JOIN и транзакции | Карта доступа и shard key | Основной путь локален |
| Читать всё с replica | Устаревшие права/балансы после записи | Определить требования согласованности | Read-after-write тест |
| Двойная запись без протокола | Частично записанные данные | Outbox/CDC или обоснованная транзакционная схема | Сбой между шагами |
| Считать копирование миграцией | Потеря новых updates/deletes | Журнал изменений и сверка | Изменения во время backfill |
| Откатывать код после удаления схемы | Старая версия больше не работает | Expand/contract и окно совместимости | Старый артефакт на новой схеме |
| Проверять права только в UI | Доступ к чужим данным | Проверки backend | Прямые запросы от другого tenant |
| Считать UUID защитой | Утечка при получении ID | Object-level authorization | Известный чужой ID |
| Лимит только на аккаунт | Распределённая перегрузка | Общие и бизнес-бюджеты | Много аккаунтов ниже лимита |
| Лимит только на число HTTP | Один дорогой batch перегружает систему | Предел стоимости операции | Большой диапазон/пакет |
| Лимит в памяти каждого worker | Суммарная квота растёт с replicas | Согласованное списание | Несколько экземпляров |
| CAPTCHA вместо всех ограничений | Проверенный бот всё равно наносит ущерб | Проверка плюс квоты | Пройденная проверка и дорогая работа |
| Бесконечная очередь | Долги и устаревшие задания | Ограничение длины/возраста | Медленный worker |
| Retry на каждом слое | Усиление сбоя | Бюджет повторов и идемпотентность | Таймаут после побочного эффекта |
| Общий кэш приватных данных | Межклиентская утечка | Контекст доступа в ключе | Два tenant с одним object ID |
| Бэкап без restore | Нечем восстанавливать | Регулярная тренировка | Изолированное восстановление |
| Секрет удалён из git, но не отозван | Старый ключ остаётся рабочим | Ротация и расследование | Старый ключ отклоняется |
| Слепое принятие кода AI | Непроверенные предположения | Review инвариантов и отказов | Негативные тесты |
| «Аудит был» без версии | Проверяли другой код | Commit → fix → deployment | Сверка артефакта |
